# Contributing & Issue Guidelines

Thank you for your interest in **GIFforge**! 

To keep the project stable, performant, and secure, we use this repository primarily for:
- 🐞 **Bug Reports**
- 💡 **Feature & Enhancement Requests**
- 📖 **Documentation Improvements**
- 📢 **Public Announcements & Release Logs**

---

### Source Code & Development
GIFforge is a **proprietary, source-closed product**. The core rendering engine, optimization heuristics, and AI frame-selection logic reside in an internal development repository.

As a result:
- **Pull Requests containing code implementations cannot be accepted or merged.**
- Contributions to documentation or issue templates, however, are welcome.

---

### Reporting a Bug 🐛
If you encounter unexpected behavior:
1. Check existing issues to see if it has already been reported.
2. Use the [Bug Report Template](https://github.com/bsbhadauria/GIFforge/issues/new?template=bug_report.md).
3. Include:
   - Your Browser & OS version (e.g., Chrome 128 on Windows 11)
   - Extension version
   - Steps to reproduce
   - Console errors (if visible)

### Suggesting an Enhancement 💡
We love user feedback!
1. Use the [Feature Request Template](https://github.com/bsbhadauria/GIFforge/issues/new?template=feature_request.md).
2. Clearly describe the problem you're trying to solve and your proposed feature.
